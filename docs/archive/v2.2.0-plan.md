# VenturePulse v2.2.0 - "Link Sharing" Implementation Plan

## Summary

Add shareable links feature allowing project owners to share private projects via time-limited URLs. Includes unique visitor tracking and a management UI.

**Key specifications:**
- 42-character alphanumeric key (mixed-case A-Za-z0-9, no symbols)
- Multiple links per project allowed
- Default 7 days expiration, max 90 days
- Unique visitor tracking (hash of IP + User-Agent)
- Session-based allowkey storage after validation

**Side fix:** Admin button shows "Admin (X pending)" when users are pending

**Status:** COMPLETED - 2026-01-08
